Compatibility is not the same as security hardening.

Insecure guest authentication and reduced SMB signing can expose traffic and data to interception or malicious network peers. Use only for a specific trusted legacy endpoint, then restore safer settings when the compatibility need ends.

05 / QUICK START

From Windows to dashboard

One workflow, one report, no simulated telemetry.

01

Run the primary workflow

Launch NetworkRepair.cmd as administrator. Press Enter for the default option 3, then type APPLY after reviewing the security notice.

02

Locate the report

Reports and rollback snapshots are saved under %ProgramData%\WindowsNetworkRepairPro. The apply report includes pre-state, post-state, action verification and monitor samples.

03

Import and inspect

Open this GitHub Pages dashboard, import the generated ApplyReport_*.json, and inspect each changed field and monitor sample.
